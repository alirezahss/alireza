# Avira Med Spa Website

A production-style React + Tailwind landing website for Avira Med Spa, built with Vite and Framer Motion.

## Stack
- React 18
- Tailwind CSS 3
- Framer Motion
- Vite 5

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Sections included
1. Hero
2. Pain agitation
3. Solution / benefits
4. Process
5. Testimonials
6. Credibility
7. Final CTA
8. Footer
